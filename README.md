## О проекте

При изменении интенсивности и сложности поступающих заданий системе требуется разное количество вычислительных ресурсов. Недостаток ресурсов приводит к накоплению очереди и увеличению задержек, а постоянное выделение максимальной мощности — к её избыточному резервированию.

**Цель проекта** — разработать и исследовать контроллер, который автоматически изменяет число обработчиков по техническим метрикам системы, сокращая выделенные ресурсы при заданном ограничении на время ожидания заданий.

Для экспериментов будет создан небольшой стенд с очередью и несколькими CPU-воркерами. Неоднородную нагрузку обеспечат реальные задачи перекодирования видео, шумоподавления и сжатия файлов. Контроллер будет использовать метрики очереди, выполнения заданий и потребления ресурсов без доступа к содержимому и прикладным параметрам заданий.

Первое решение будет основано на эвристиках. В дальнейшем планируется построить ML-модель производительности системы и проверить, улучшает ли её использование решения о масштабировании.
